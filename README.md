# SCB – App VáDeBicicleta (Sprint 1)

Site estático (HTML/CSS/JS), sem build.

## Deploy na Vercel
Opção 1 (CLI):
  npm i -g vercel
  vercel --prod

Opção 2 (GitHub): suba esta pasta num repositório, importe em vercel.com/new
e deixe Framework Preset = Other, sem Build Command.

Opção 3: arraste a pasta em vercel.com/new.
